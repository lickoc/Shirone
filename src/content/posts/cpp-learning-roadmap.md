C++ 是一门「入门容易、精通极难」的语言。它的学习曲线陡峭，但如果路线规划得当，可以少走很多弯路。本文按阶段梳理一条相对完整的学习路线。

## 阶段划分总览

| 阶段 | 目标 | 大致周期 |
|------|------|----------|
| 一、语法基础 | 能写能跑，理解编译链接 | 1–2 个月 |
| 二、面向对象 | 掌握封装、继承、多态 | 1–2 个月 |
| 三、标准库与泛型 | 熟练使用 STL，理解模板 | 2–3 个月 |
| 四、现代 C++ | 掌握 C++11/14/17/20 核心特性 | 2–3 个月 |
| 五、工程与底层 | 构建、调试、内存与性能 | 长期 |
| 六、方向深入 | 后端 / 游戏 / 嵌入式 / 基础架构 | 长期 |

## 阶段一：语法基础

先让代码跑起来，再谈风格和优化。

- 开发环境：Linux + GCC/Clang，或 VS Code + CMake，或 Visual Studio
- 基本语法：变量、类型、运算符、流程控制、函数、数组、指针与引用
- 编译链接：预处理 → 编译 → 汇编 → 链接，理解头文件与源文件的组织
- 内存模型初步：栈、堆、`new`/`delete`

**本阶段目标**：独立写出几百行的小程序，遇到编译错误能自己读懂报错信息。

:::tip
不要一上来就啃《C++ Primer》的全部内容。先快速过一遍语法，把书当字典用，遇到问题再回头查。
:::

## 阶段二：面向对象

- 类与对象、构造/析构函数、拷贝控制
- 封装、继承、多态、虚函数与虚函数表
- 运算符重载、友元
- RAII 思想：资源获取即初始化

**关键理解**：虚函数表如何实现多态、为什么要虚析构、对象切片问题。

## 阶段三：标准库与泛型编程

- 容器：`vector`、`list`、`deque`、`map`、`unordered_map`、`set`
- 迭代器与算法：`<algorithm>` 中的 `sort`、`find`、`transform`
- 智能指针：`unique_ptr`、`shared_ptr`、`weak_ptr`
- 模板：函数模板、类模板、特化、可变参数模板
- `lambda` 表达式与函数对象

**本阶段目标**：能用 STL 组合出简洁高效的代码，不再手写链表和排序。

## 阶段四：现代 C++

C++11 之后语言发生了质变，这部分是现代 C++ 的核心。

- 移动语义：右值引用、`std::move`、完美转发
- `auto`、范围 `for`、`constexpr`、`nullptr`、`enum class`
- 并发：`std::thread`、`mutex`、`condition_variable`、`atomic`、内存序
- C++17：结构化绑定、`if constexpr`、`optional`、`variant`、`string_view`、文件系统
- C++20：概念（concepts）、协程、范围（ranges）、模块（modules）

**本阶段目标**：写出的代码符合现代 C++ 风格，能正确使用移动语义避免无谓拷贝。

## 阶段五：工程与底层

- 构建系统：CMake 的基本用法与项目组织
- 调试：GDB / LLDB、断点、调用栈、core dump 分析
- 内存与性能：内存布局、缓存友好、`perf` / `valgrind` / Sanitizer
- 编译期：模板元编程、SFINAE、类型萃取
- 代码规范与静态检查：clang-format、clang-tidy

## 阶段六：选择方向深入

| 方向 | 需要补的知识 |
|------|--------------|

| 游戏开发 | 图形学、Unreal/Unity C++、ECS 架构、物理引擎 |
| 嵌入式 | 交叉编译、寄存器操作、RTOS、资源受限优化 |

## 推荐资源

**入门书籍**

- 《C++ Primer（第 5 版）》——最全面的入门教材
- 《Essential C++》——更轻量的快速入门

**进阶书籍**

- 《Effective C++》/《Effective Modern C++》——条款式经验
- 《深度探索 C++ 对象模型》——理解编译器背后做了什么
- 《C++ Concurrency in Action》——并发编程必读

**在线资源**

- [cppreference.com](https://en.cppreference.com/)——最权威的参考手册
- [C++ Core Guidelines](https://isocpp.github.io/CppCoreGuidelines/)——现代 C++ 最佳实践
- [LearnCpp](https://www.learncpp.com/)——结构化教程

## 学习建议

1. **动手优先**：每个知识点都要写代码验证，光看不会。
2. **读优秀源码**：STL 实现、小型开源项目，比看十本书有用。
3. **重视调试能力**：会调试的人学得快一个数量级。
4. **不要过早优化**：先写对，再写快。
5. **持续跟进标准**：C++ 每三年一版，保持更新。
